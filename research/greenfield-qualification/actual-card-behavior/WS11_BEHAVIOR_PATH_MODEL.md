# WS11 behavior-path model

WS11 supersedes WS10's Q6 classification method without rewriting its historical evidence. It binds each exact WS02 Oracle identity to the semantic lines of the exact Forge script at pin `8c7e9afb8e6caee88644b94e25da5852e36f8928`. Normalized semantic lines form an immutable `forge-path-v1` signature.

A shared signature qualifies an identity only when a registry witness names that exact signature, executed successfully, asserted engine state rather than stdout alone, retained an immutable trace SHA-256, and was adjudicated against official rules when semantic adjudication was needed. Similar words, source presence, loadability, construction, absence of suspicious markers, and global WS01/WS05/WS06 results are never behavior proof.

The initial registry is intentionally empty because no predecessor evidence proves exact identity-to-path execution across the 1,678-card corpus. Therefore the successor gate remains fail-closed. This is a substantive correction: it materializes exact path mappings and the missing-proof frontier instead of reproducing WS10's invalid `CONDITIONAL_FULL` inference.

Official semantic authority is the current [Magic Comprehensive Rules](https://magic.wizards.com/en/rules) and [Commander rules](https://mtgcommander.net/index.php/rules/), never engine majority.
